# VSCode Extensions

## Themes

```bash
# Themes
codium --install-extension catppuccin.catppuccin-vsc
codium --install-extension enkia.tokyo-night
codium --install-extension mvllow.rose-pine
codium --install-extension zhuangtongfa.material-theme
```

## Vim Emulation

```bash
codium --install-extension vscodevim.vim
```

## Linters, Formatters, etc

codium --install-extension charliermarsh.ruff
